# ops-define-incident-response

## O que faz
Severity levels, oncall, papéis, fluxo, comms templates, postmortem blameless.

## Quando você invoca
Antes do go-live. Após primeiro incidente real. Ao adicionar canal/produto.

## O que a IA faz
1. Severity matrix (SEV1/2/3).
2. Papéis: IC, Tech Lead, Comms, Scribe.
3. Fluxo: detectar → declarar → war room → contenção → mitigação → resolução → postmortem.
4. Templates de comunicação.
5. Política de postmortem (≤5 dias úteis).
6. Drills periódicos.
