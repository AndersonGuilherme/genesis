# Tests: validate-idea

## Pré-condição
- `docs/research/assumptions.md` contém premissas com confiança 1-2 e impacto alto/fatal.

## Prompts canônicos
- "como sei se essa ideia tem demanda?"
- "quero validar willingness to pay"
- "não sei se o público-alvo é esse mesmo"

## Comportamentos esperados
- [ ] Lista premissas críticas pendentes.
- [ ] Para cada uma, propõe experimento concreto (entrevista, smoke, piloto, etc.).
- [ ] Define critério de sucesso e de falha **antes** de rodar.
- [ ] Registra experimentos em `docs/research/validation-plan.md`.
- [ ] Após resultado, atualiza confiança em `assumptions.md`.

## Anti-padrões
- [ ] NÃO aceita "minha família achou legal".
- [ ] NÃO define critério depois do experimento.
- [ ] NÃO confirma premissa só por concordância em entrevistas.
- [ ] NÃO pula validação de premissas fatais para "ganhar velocidade".
