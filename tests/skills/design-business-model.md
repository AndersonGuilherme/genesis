# Tests: design-business-model

## Pré-condição
- `business-model.md` rascunho.
- `target-users.md` definido.

## Prompts canônicos
- "vamos definir os planos"
- "quanto cobrar?"
- "como vamos vender?"

## Comportamentos esperados
- [ ] Estrutura planos (Starter / Pro / Business ou equivalente, máx 4).
- [ ] Pricing com âncora justificada.
- [ ] Unit economics estimados (CAC, LTV, payback) em faixas.
- [ ] Motion de GTM declarada (self-service, inside, parceria).
- [ ] Lista de experimentos de pricing planejados.
- [ ] Sugere ADR para "modelo de receita primário".

## Anti-padrões
- [ ] NÃO cria mais de 4 planos.
- [ ] NÃO endossa desconto para o primeiro cliente.
- [ ] NÃO aceita pricing sem âncora.
- [ ] NÃO ignora LTV/CAC < 3 como risco crítico.
